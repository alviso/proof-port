Proof Port

An agent ports a custom SAP transaction. The old transaction grades the new app, on tests sealed before the port began.

Peter Varga

Thousands of custom SAP transactions

  • Big SAP customers run Z code their consultants wrote over twenty years.
  • Moving to S/4HANA and a clean core means rewriting it.
  • With coding agents, the rewrite is the easy part.
  • Proving the rewrite does the same thing is what nobody can sign off.

The old transaction is the judge

The old transaction in SAP, run by batch input
↕↕
1

Extract

Screens, flow logic, ABAP and dictionary. SAP's own objects listed by name, never read.

2

Oracle

Plays screen inputs through the old transaction, records messages and rows, puts the tables back.

3

Tests

Agent one writes cases from the extract; the oracle answers. SHA-256 into a public commit.

4

Port

Agent two builds RAP, OData V4 and Fiori Elements on the same tables, without the cases.

5

Grade

Each sealed case through the old screen and the new service; messages and rows compared. Then breaks.

6

Proof page

Score, every difference in words, the seal, the breaks, and what wasn't checked.
